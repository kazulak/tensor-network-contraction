# References

The sources used in [topics/](../topics/). A paper's PDF is included here **only when its licence
allows redistribution**. For everything else, run `./fetch.sh` to download the arXiv versions into
`local/`, which is not committed.

Licences were checked on each paper's arXiv page on 2026-09-27. A ✔ means the cited
sections/equations were checked against the text.
